Répéteur Wi-Fi avec un Raspberry Pi

Guide en français, sans publicité. Texte réécrit à partir du tutoriel de Pi My Life Up (testé sur Raspberry Pi 5, Raspberry Pi OS Bookworm, mis à jour en juin 2024). Ce n’est pas une traduction mot à mot. Article original

Le principe

Le Raspberry Pi capte votre Wi-Fi avec un premier adaptateur et le rediffuse avec un second. Un répéteur est différent d’un point d’accès Wi-Fi : il reçoit sa connexion par Wi-Fi, pas par un câble Ethernet.

Il faut donc deux adaptateurs Wi-Fi, dont un qui sait fonctionner en mode point d’accès. Sur un Pi avec Wi-Fi intégré (comme le Pi 3B+), le Wi-Fi intégré sert d’entrée et il suffit d’une clé USB compatible pour la sortie.

Le débit sera réduit. Les données passent par deux liaisons Wi-Fi successives avant d’arriver à l’appareil.

Matériel

  • Un Raspberry Pi, une carte microSD et une alimentation
  • Deux adaptateurs Wi-Fi (un seul à ajouter si le Pi a déjà le Wi-Fi intégré)
  • Un boîtier (facultatif)

Il faut aussi Raspberry Pi OS Bookworm ou plus récent, qui utilise déjà NetworkManager. C’est cet outil qui fait tout le travail.

Vos valeurs

Remplissez ces champs : les commandes ci-dessous se mettent à jour toutes seules. Rien n’est envoyé ni enregistré.

Installation

1. Mettre le système à jour

sudo apt update
sudo apt upgrade

2. Connecter le Pi au Wi-Fi à étendre

Si ce n’est pas déjà fait, suivez le guide se connecter au Wi-Fi sur le Raspberry Pi. Cet adaptateur (souvent wlan0) reçoit le signal.

3. Trouver le nom des adaptateurs

iwconfig

Vous verrez deux interfaces. L’une est déjà connectée à votre réseau, c’est l’entrée. L’autre est libre : c’est elle qui diffusera le Wi-Fi étendu. Dans cet exemple, elle s’appelle wlan1. Si le vôtre est différent, changez-le dans le champ plus haut.

4. Vérifier le mode point d’accès

nmcli -f WIFI-PROPERTIES.AP device show <ADAPTATEUR>

La réponse doit contenir yes. Sinon, cet adaptateur ne convient pas : il faut en changer.

5. Activer le répéteur

sudo nmcli d wifi hotspot ifname <ADAPTATEUR> ssid <NOM_DU_WIFI> password <MOT_DE_PASSE>

Une seule commande suffit. NetworkManager gère le reste et partage la connexion déjà active.

6. Contrôler que ça tourne

nmcli con show

Une ligne nommée Hotspot doit apparaître, associée à votre adaptateur de sortie.

7. Tester

Connectez un téléphone ou un ordinateur au nouveau Wi-Fi. Si tout fonctionne, c’est terminé.

En cas de problème

Si l’appareil n’arrive pas à se connecter, désactivez les trames de gestion protégées. Certains adaptateurs ne les gèrent pas bien.

sudo nmcli con modify Hotspot wifi-sec.pmf disable

Pour supprimer le répéteur et recommencer :

sudo nmcli con delete Hotspot

Avec un VPN

Ce guide se combine avec le guide du point d’accès VPN (en anglais). À l’étape 13 de ce guide, remplacez ses commandes par celles-ci. Le trafic de l’adaptateur de sortie passe alors dans le tunnel.

sudo iptables -t nat -A POSTROUTING -o tun0 -j MASQUERADE
sudo iptables -A FORWARD -i tun0 -o <ADAPTATEUR> -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A FORWARD -i <ADAPTATEUR> -o tun0 -j ACCEPT

Le reste du guide VPN ne change pas.

Vous avez maintenant un répéteur Wi-Fi qui consomme peu. Pour d’autres projets, voir les guides Raspberry Pi de Pi My Life Up.
